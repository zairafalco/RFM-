# 📊 RFM Customer Segmentation

> Customer segmentation using RFM analysis and unsupervised clustering models.

---

## 🎯 Project Overview

This project applies **RFM (Recency, Frequency, Monetary)** analysis to segment customers based on their purchasing behaviour. The goal is to identify distinct customer groups to support targeted marketing strategies and business decision-making.

---

## 🔍 What is RFM?

| Metric | Description |
|--------|-------------|
| **Recency** | How recently did the customer make a purchase? |
| **Frequency** | How often do they purchase? |
| **Monetary** | How much do they spend? |

# 🍷 Wine Quality Classification

> Wine quality prediction using Machine Learning — Random Forest Classifier on physicochemical data.

---

## 🎯 Project Overview

This project predicts wine quality based on **physicochemical properties** such as acidity, sugar, pH and alcohol content. The output is a binary classification: **good** (score > 5) vs **bad** (score ≤ 5).

---

## 📊 Dataset

The dataset contains the following input variables (physicochemical tests):

| # | Feature | # | Feature |
|---|---------|---|---------|
| 1 | Fixed acidity | 7 | Total sulfur dioxide |
| 2 | Volatile acidity | 8 | Density |
| 3 | Citric acid | 9 | pH |
| 4 | Residual sugar | 10 | Sulphates |
| 5 | Chlorides | 11 | Alcohol |
| 6 | Free sulfur dioxide | 12 | **Quality** (target) |

> 🎯 **Output variable:** Quality — `good` (score > 5) / `bad` (score ≤ 5)
